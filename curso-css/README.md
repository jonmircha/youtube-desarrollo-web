# Cursos de _CSS_

Los códigos de los tres cursos de _CSS_ de la serie **Curso _HTML_ y _CSS_** (2/5 a 4/5). Cada tema tiene su página `.html` y su hoja en `css/`.

## Fundamentos de _CSS_: selectores, cascada y modelo de caja (2/5)

[Ver el curso](https://www.youtube.com/watch?v=K3xmRF8ab1o) · Selectores, pseudoclases y pseudoelementos, la cascada, la especificidad y la herencia, el modelo de caja y el posicionamiento.

| Archivo                   | Qué hay                                                              |
| ------------------------- | -------------------------------------------------------------------- |
| `index.html`              | Sintaxis, selectores, cascada, especificidad y herencia.             |
| `box-model.html`          | El modelo de caja: tamaños, bordes, márgenes, rellenos y `display`.  |
| `positions.html`          | Los cinco tipos de posicionamiento y `z-index`.                      |
| `positions-examples.html` | Ejercicios: cabecera fija contra _sticky_, _slides_ y ventana modal. |

## Colores, unidades, variables y fuentes en _CSS_ (3/5)

[Ver el curso](https://www.youtube.com/watch?v=p_lT7AgpEMU) · Colores, unidades de medida, variables y funciones, fuentes, fondos y los estilos de imágenes, listas, tablas y formularios.

| Archivo                    | Qué hay                                                      |
| -------------------------- | ------------------------------------------------------------ |
| `colors.html`              | Nombres, hexadecimal, _RGB_, _HSL_ y opacidad.               |
| `units.html`               | Píxeles, _em_, _rem_, porcentajes y unidades del _viewport_. |
| `variables-functions.html` | _Custom properties_, `calc()`, `min()`, `max()` y `clamp()`. |
| `fonts-texts.html`         | Fuentes, `@font-face`, _Google Fonts_ y estilos de texto.    |
| `border-outline.html`      | `border-radius` y `outline`.                                 |
| `backgrounds.html`         | Todas las propiedades de los fondos y los fondos múltiples.  |
| `images.html`              | Estilos de imágenes.                                         |
| `lists.html`               | Estilos de listas y texto en columnas.                       |
| `tables.html`              | Estilos de tablas.                                           |
| `forms.html`               | Estilos de formularios y el formulario de contacto.          |

## Sombras, degradados, filtros, transiciones y animaciones en _CSS_ (4/5)

[Ver el curso](https://www.youtube.com/watch?v=mVhoGXkDbMw) · Efectos visuales, efectos con el _scroll_, transiciones, transformaciones y animaciones.

| Archivo                   | Qué hay                                                                       |
| ------------------------- | ----------------------------------------------------------------------------- |
| `visual-effects.html`     | Sombras, degradados, filtros, modos de mezcla, `clip-path` y `shape-outside`. |
| `scroll-one-page.html`    | Un sitio _one page_ con `scroll-behavior` y `scroll-margin`.                  |
| `scroll-snap-slides.html` | _Slides_ y carrusel con `scroll-snap`.                                        |
| `motion.html`             | Transiciones, transformaciones 2D y 3D, animaciones y sus ejercicios.         |
