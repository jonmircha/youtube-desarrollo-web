# Fundamentos de _HTML_ desde cero

Los códigos del primer curso de la serie **Curso _HTML_ y _CSS_** (1/5): [Fundamentos de _HTML_ desde cero](https://www.youtube.com/watch?v=-oK6zL01fNM). En casi ocho horas vemos desde la instalación del _software_ y la estructura básica de un documento hasta la semántica, las imágenes, los vectores, las tablas, los enlaces, el audio y el video, los formularios, las metaetiquetas para _SEO_ y redes sociales, y la accesibilidad.

## Archivos

| Archivo      | Qué hay                                                                       |
| ------------ | ----------------------------------------------------------------------------- |
| `index.html` | El documento que construimos a lo largo del curso, tema por tema.             |
| `hola.html`  | El primer documento _HTML_ del curso.                                         |
| `assets`     | La hoja de estilos y el _script_ de los temas «Estilos» y «Scripts».          |
| `img`        | Las imágenes y los vectores de los ejemplos.                                  |
| `media`      | El audio y el video de los ejemplos, y la hoja de trucos de _Emmet_ en _PDF_. |
