# Desarrollo Web desde Cero 🚀

Hola, soy tu amigo y docente digital **Jonathan MirCha**, bienvenid@s a mi **Curso Desarrollo Web desde Cero**.

Es una ruta de cursos totalmente **gratuitos** en mi canal de [_YouTube_](https://youtube.com/@jonmircha) para empezar a programar para la _web_ sin saber nada: de las herramientas a tu primer sitio publicado. En este repositorio están los códigos de los cursos que los tienen, y en mi sitio, los apuntes de cada uno.

## Cómo usar los códigos

No necesitas instalar nada: clona o descarga el repositorio y abre cualquier archivo `.html` en tu navegador.

```bash
git clone https://github.com/jonmircha/youtube-desarrollo-web.git
```

El sitio que maquetamos en el curso de _Bootstrap_ vive en [`docs`](./docs), porque _GitHub Pages_ lo publica desde esa carpeta: https://jonmircha.github.io/youtube-desarrollo-web/
