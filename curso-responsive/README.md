# _Responsive design_, _container queries_ y arquitectura _CSS_

Los códigos del último curso de la serie **Curso _HTML_ y _CSS_** (5/5): [_Responsive design_, _container queries_ y arquitectura _CSS_](https://www.youtube.com/watch?v=udGrXWeJp1Y). En casi diez horas vemos contenedores y multimedia flexibles, _media queries_, _breakpoints_, _feature queries_ y _container queries_, el diseño fluido y, en la segunda mitad, la arquitectura _CSS_: metodologías como _BEM_, _frameworks_, preprocesadores y herramientas.

## Para comenzar

Descarga [`responsive-arquitectura.zip`](./responsive-arquitectura.zip): son los archivos con los que empezamos a trabajar en el curso.

## Archivos

| Archivo                       | Qué hay                                            |
| ----------------------------- | -------------------------------------------------- |
| `responsive-arquitectura.zip` | Los archivos para comenzar el curso.               |
| `index.html`                  | El documento que construimos a lo largo del curso. |
| `css/grid.css`                | La _grid_ responsiva artesanal con _Flexbox_.      |
| `css/init.css`                | Los estilos iniciales del documento.               |
| `css/print.css`               | Los estilos para imprimir.                         |
| `assets` e `img`              | El video y las imágenes de los ejemplos.           |
